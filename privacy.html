Butler Privacy Policy

Last updated October 25, 2026

Butler is a private, single-user voice assistant that runs on its owner's home server. Only the owner uses it. This page explains what it does with Google data.

What Butler accesses

With the owner's permission, Butler reads, creates, changes and deletes events in the owner's Google Calendar, and reads the list of his calendars. It does not access any other Google data.

How the data is used

Calendar data is used only to answer the owner's own requests, such as telling him what is on his schedule or adding an event he asked for. To understand a request and write a reply, the relevant calendar details are sent to Anthropic's Claude API, which processes them under Anthropic's commercial terms. Nothing else receives the data.

What is stored

The sign-in token is stored only on the owner's home server. Butler keeps a short log of recent conversations there so it can follow a conversation; it does not keep a copy of the calendar.

Sharing

Google data is never sold, shared with other people, used for advertising, or used to train AI models. Butler's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
